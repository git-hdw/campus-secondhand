# 数据库设计

版本：2026-10-29，依据 schema.sql、实体及 SchemaMigration。库名 campus_secondhand。旧设计归档，不再使用 sys_user、trade_order 等规划表名。

## 1. 表与关系

当前六张业务表：users、categories、products、orders、favorites、messages；三张技术表：request_dedup、auth_sessions、schema_migrations。全部采用 InnoDB；已有业务库字符排序规则保留，历史业务表为 utf8_unicode_ci，不将其误写为已经统一 utf8mb4。

users 与商品、订单买卖双方、收藏、消息双方、请求去重、登录会话为一对多。products 与订单、收藏、消息为一对多。products.category 引用 categories.name；categories.parent_id 为可空自引用。共 13 条外键，采用 ON DELETE RESTRICT / ON UPDATE RESTRICT。账号逻辑删除不删除关联历史。

## 2. 关键约束与状态

用户名、邮箱、学号分别唯一；分类编码唯一；收藏(user_id,product_id)唯一；订单号唯一。商品状态为 0/1/2/3，分别表示在售/已成交/已下架/待审核；订单状态为 0/3/4，分别表示待见面/已完成/已取消。价格使用 DECIMAL(10,2)。

迁移增加 orders.pending_product_id 和 completed_product_id 两个虚拟生成列，分别在状态 0、3 时取 product_id，并建立唯一索引；数据库因此拒绝同一有效商品重复待见面或重复完成的记录。跨状态一致性仍通过 OrderTradeService 的行锁、状态判断和事务保证。

## 3. 历史迁移

SchemaMigration 在初始化完成后执行幂等版本 1：转换 MyISAM 表至 InnoDB；增加 legacy_product_id；将失联商品订单原编号保存后把 product_id 置空；检查其他引用关系；增加外键及唯一索引；成功后登记 schema_migrations。DDL 不具有整体事务回滚能力，正式库迁移前必须完整备份，失败时可按缺失约束继续执行，不得盲目回滚或删除业务记录。

legacy_product_id 只保存历史原编号，不是外键。失联订单保留订单号、双方、价格、状态和时间。新的订单由业务层要求非空有效商品。初始化 CREATE TABLE IF NOT EXISTS 不替代迁移逻辑。

版本 2 增加 orders.snapshot_json（MEDIUMTEXT，可空）。新订单在下单事务内保存商品编号、卖家编号、标题、描述、图片值、地点、分类、成色、价格及原价的 JSON 快照。原有订单保持 NULL，避免将当前商品信息误记为历史成交信息；用户端对旧订单保留兼容展示。快照中的图片引用不代表图片文件永久保存。

## 4. 技术表

auth_sessions 保存随机会话 ID、用户 ID、创建时间、到期时间、撤销时间，不保存原始 JWT。SessionMaintenance 每小时清理到期或撤销超过 30 天的会话，每次最多 1000 条，保留有效会话。request_dedup 以用户、业务范围和请求标识为联合主键，保存请求摘要及原响应；业务写入和响应保存处于同一事务。为保留重试幂等语义，本轮不清理去重记录，其长期归档策略仍待确定。schema_migrations 保存已完成迁移版本及时间。

## 5. 初始化字段定义

以下摘录自当前 schema.sql，不含演示账号数据；启动时还会应用上文所述迁移列、索引与外键。

```sql
-- Versioned references and legacy order migration are applied by SchemaMigration after initialization.
CREATE TABLE IF NOT EXISTS auth_sessions (
  id VARCHAR(36) CHARACTER SET ascii COLLATE ascii_bin PRIMARY KEY,
  user_id BIGINT NOT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  expires_at DATETIME NOT NULL,
  revoked_at DATETIME NULL,
  KEY idx_sessions_user_active (user_id, revoked_at, expires_at)
) ENGINE=InnoDB;

CREATE TABLE IF NOT EXISTS request_dedup (
  user_id BIGINT NOT NULL,
  scope VARCHAR(24) NOT NULL,
  request_key VARCHAR(80) CHARACTER SET ascii COLLATE ascii_bin NOT NULL,
  payload_hash CHAR(64) NOT NULL,
  response_json MEDIUMTEXT NULL,
  created_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (user_id, scope, request_key),
  KEY idx_request_dedup_created (created_time)
) ENGINE=InnoDB;

CREATE TABLE IF NOT EXISTS users (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  username VARCHAR(50) NOT NULL,
  email VARCHAR(100) NOT NULL,
  student_no VARCHAR(20) NULL,
  password VARCHAR(100) NOT NULL,
  phone VARCHAR(20) NULL,
  avatar TEXT NULL,
  bio VARCHAR(200) NULL,
  location VARCHAR(100) NULL,
  qq VARCHAR(20) NULL,
  wechat VARCHAR(40) NULL,
  status INT NOT NULL DEFAULT 1,
  role INT NOT NULL DEFAULT 0,
  created_time DATETIME NULL,
  updated_time DATETIME NULL,
  deleted INT NOT NULL DEFAULT 0,
  UNIQUE KEY uk_users_username (username),
  UNIQUE KEY uk_users_email (email),
  UNIQUE KEY uk_users_student_no (student_no)
) ENGINE=InnoDB;

CREATE TABLE IF NOT EXISTS categories (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(40) NOT NULL,
  description VARCHAR(200) NULL,
  parent_id BIGINT NULL,
  icon VARCHAR(100) NULL,
  sort_order INT NOT NULL DEFAULT 0,
  status INT NOT NULL DEFAULT 1,
  created_time DATETIME NULL,
  updated_time DATETIME NULL,
  UNIQUE KEY uk_categories_name (name)
) ENGINE=InnoDB;

CREATE TABLE IF NOT EXISTS products (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  title VARCHAR(60) NOT NULL,
  description VARCHAR(2000) NULL,
  price DECIMAL(10,2) NOT NULL,
  original_price DECIMAL(10,2) NULL,
  category VARCHAR(40) NULL,
  `condition` VARCHAR(20) NULL,
  trade_place VARCHAR(40) NULL,
  images MEDIUMTEXT NULL,
  view_count INT NOT NULL DEFAULT 0,
  status INT NOT NULL DEFAULT 0,
  created_time DATETIME NULL,
  updated_time DATETIME NULL,
  sold_time DATETIME NULL,
  KEY idx_products_sale_created (status, created_time, id),
  KEY idx_products_user (user_id)
) ENGINE=InnoDB;

CREATE TABLE IF NOT EXISTS favorites (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  product_id BIGINT NOT NULL,
  created_time DATETIME NULL,
  UNIQUE KEY uk_favorite (user_id, product_id)
) ENGINE=InnoDB;

CREATE TABLE IF NOT EXISTS messages (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  sender_id BIGINT NOT NULL,
  receiver_id BIGINT NOT NULL,
  product_id BIGINT NULL,
  content VARCHAR(500) NOT NULL,
  is_read INT NOT NULL DEFAULT 0,
  created_time DATETIME NULL,
  KEY idx_messages_conversation (sender_id, receiver_id, created_time),
  KEY idx_messages_unread (receiver_id, is_read)
) ENGINE=InnoDB;

CREATE TABLE IF NOT EXISTS `orders` (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  order_no VARCHAR(32) NOT NULL,
  buyer_id BIGINT NOT NULL,
  seller_id BIGINT NOT NULL,
  product_id BIGINT NOT NULL,
  price DECIMAL(10,2) NOT NULL,
  status INT NOT NULL DEFAULT 0,
  created_time DATETIME NULL,
  updated_time DATETIME NULL,
  completed_time DATETIME NULL,
  snapshot_json MEDIUMTEXT NULL,
  UNIQUE KEY uk_orders_no (order_no),
  KEY idx_orders_product_status (product_id, status),
  KEY idx_orders_buyer (buyer_id, created_time),
  KEY idx_orders_seller (seller_id, created_time)
) ENGINE=InnoDB;


CREATE TABLE IF NOT EXISTS schema_migrations (
  version INT PRIMARY KEY,
  applied_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB;
```
