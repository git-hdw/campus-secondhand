# 需求规格说明书

版本：2026-10-29 当前实现基线。此前设计已归档到 review-2026-10-29/历史设计，不再作为现行需求。

## 1. 系统目标与范围

系统面向高校学生提供闲置商品发布、管理审核、检索、咨询、收藏及线下交易管理。采用 Vue 3 前端与 Spring Boot 3 后端分离架构，数据保存在 MySQL。当前没有在线支付、物流、退款、商品评论、举报、独立校区管理、邮件找回密码或 Redis 缓存。学号为自行登记，系统不宣称学校认证；确认收货记录买家声明，不核验见面位置。

## 2. 角色及权限

| 角色 | 权限 |
| --- | --- |
| 游客 | 浏览在售商品、分类与公开统计；查看卖家公开资料；注册及登录 |
| 学生 | 维护本人资料、商品、收藏和消息；购买他人商品；参与本人订单；管理本账号登录会话 |
| 管理员 | 查询管理统计；维护账号状态、审核商品、维护分类、管理消息与订单；不能绕过买家确认规则 |

权限在服务端校验，前端导航及路由守卫不构成安全边界。公开用户资料仅返回展示必要字段，密码哈希不通过 JSON 返回。

## 3. 功能需求与验收规则

| 编号 | 功能 | 验收要求 |
| --- | --- | --- |
| FR01 | 注册与登录 | 用户名、邮箱、学号唯一；密码通过 BCrypt 保存；支持用户名或学号登录；禁用或已删除账号不可登录 |
| FR02 | 会话管理 | JWT 绑定用户 ID、版本、凭据标记和唯一会话 ID；退出后服务端拒绝旧令牌；只能撤销自己的会话；支持全部退出；修改密码使旧会话失效 |
| FR03 | 商品发布 | 标题、金额、分类、成色、地点及图片通过校验；发布后待审核；相同重试标识不重复创建 |
| FR04 | 商品浏览 | 服务端分页、关键词、分类、成色、价格与排序；首页使用真实统计及最新八件商品；缺图、空列表和接口失败有反馈 |
| FR05 | 商品编辑与删除 | 校验归属与交易状态；保留已有历史地点；有订单或关联消息的商品不可删除；允许删除时同步清理收藏 |
| FR06 | 收藏 | 重复收藏返回原记录；服务端分页；取消收藏后正确刷新页码与总数 |
| FR07 | 下单 | 不能自购；必须在售且没有待见面或已完成订单；价格由数据库确定；并发请求最多形成一笔待见面订单 |
| FR08 | 订单流转 | 仅买家确认完成；双方可取消待见面订单；订单与商品变更同事务；失败回滚；结束后不可重复变更 |
| FR09 | 订单查询 | 分页查询本人订单，支持状态及商品筛选；新订单保存下单时商品快照，个人订单与结果页优先展示快照；历史失联订单保留原商品编号和已有订单内容 |
| FR10 | 消息 | 私信、未读计数、已读、商品关联及失败重试；会话摘要分页；历史消息按游标每批最多 50 条；搜索覆盖历史消息和商品标题 |
| FR11 | 个人中心 | 资料、发布、收藏、订单、浏览历史和草稿；我的发布服务端分页，统计保持账号全量口径；草稿按账号隔离；登录会话可查看及退出 |
| FR12 | 管理端 | 用户状态、商品审核/上下架、分类、订单、消息和统计；分类计数分组查询；有关联商品的分类不可删除 |

## 4. 状态与数据规则

商品：0 在售、1 已成交、2 已下架、3 待审核。订单：0 待见面、3 已完成、4 已取消。待见面期间商品仍为 0，通过 pendingOrder 显示锁定状态。用户角色 0 普通用户、1 管理员；状态 0 禁用、1 启用。

原有 63 笔失联商品订单通过迁移保留订单和原商品编号，原编号保存至 legacy_product_id，有效引用 product_id 置空。不得为历史订单伪造商品或删除订单来满足外键。新的有效商品引用由外键保护。

## 5. 非功能需求

Controller 仅负责 HTTP 参数绑定和委派；ApplicationService 处理权限和业务编排，领域 Service 管理事务，Repository 访问数据库。全部业务表采用 InnoDB。密码和签名密钥外置；列表禁止逐记录读取关联实体；分页响应包含 items、total、page、pageSize。业务错误采用统一 JSON 与对应 HTTP 状态。

前端保持黄黑品牌色和统一控件；登录、注册使用相同比例。按当前验收范围检查桌面，不宣称完成 Edge 或窄屏专项认证。测试应覆盖会话撤销、越权、并发、回滚、外键拒绝、历史迁移、分页边界及前端交互。

## 6. 未纳入本轮的扩展

分布式部署、在线支付、邮件密码找回、登录限流、生产监控及大规模压力测试不属于已完成功能。新订单已有商品内容快照，旧订单缺少原始内容时不进行伪造回填；快照不等于图片文件永久归档。现有会话记录不等同于设备硬件识别。
